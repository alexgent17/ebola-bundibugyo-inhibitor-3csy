# ebola-bundibugyo-inhibitor-3csy
Open-source in-silico drug discovery repository featuring molecular docking (AutoDock Vina) and ADMET profiling (SwissADME) for a novel lead inhibitor targeting the Bundibugyo Ebola virus glycoprotein (PDB: 3CSY).
